# BookBot

BookBot is a very simple project mainly to practice Python while working through the Boot.dev course. It's intended as a learning exercise.

## Description

A Python command-line program that reads the full text of a book from a `.txt` file and generates a report about it.

It primarily does two things:

* Counts the total number of words in the document.
* Counts the frequency of each individual character (e.g., how many times `a`, `b`, or `e` appears).

## How to Run

Run the program by providing the path to any `.txt` file:

```bash
python3 main.py books/<file>.txt
```

For example:

```bash
python3 main.py books/frankenstein.txt
```
